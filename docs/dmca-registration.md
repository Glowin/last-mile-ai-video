# 先确定真实主体

KakaReel 当前按个人向 Pancake 申请。公司办公地址可以作为获准的通信地址，但不证明公司是 KakaReel 的运营主体。登记前需决定实际服务提供者并确保名称及街道地址真实；不要只为隐藏姓名而填写不对应的公司。

美国版权局要求提供服务提供者完整法定名称、实际街道地址及别名，以及代理名称、组织、邮寄地址、电话与邮箱。相关登记信息供公众查询，网站也须公开相应代理联系信息。服务提供者地址一般不能用邮政信箱替代，例外须先获官方批准；代理地址则可用邮政信箱。聘请代理不等于免于提供真实服务提供者信息。[官方 FAQ](https://www.copyright.gov/dmca-directory/faq.html)。

# 注册顺序

1. 打开[美国版权局官方入口](https://www.copyright.gov/dmca-directory/)，选择 Login/Register，建立登记管理账号。
2. 添加真实服务提供者；别名包括 KakaReel 和 kakareel.com。
3. 指定一位代理，可为本人、真实职责职位／部门或第三方代理；填写其可接收通知的地址、电话及邮箱。
4. 提交前核对公开预览，确认姓名／地址公开选择及付款。官网 FAQ 当前费用为每次登记、修订或重交 US$6；登记需在三年到期前更新／续期，修订或重交会重算三年期限。以提交页实际金额为准。
5. 提交成功后，在公开 Directory 检索到有效记录，再在站内版权政策公开一致的代理信息，保存回执并设置续期提醒。

登记是寻求适用 safe harbor 的条件之一，不等于自动获得全面免责。普通客服版权举报入口不等于已登记代理；当前 support@kakareel.com 只作为普通举报渠道，不标注“registered DMCA agent”。[官方说明](https://www.copyright.gov/dmca-directory/)。

本轮没有提交身份／地址、开通收费代理或创建续期自动任务。经营主体及公开信息选择需先由站点经营者确定；Waffo 页面和功能整改不依赖伪造此登记状态。
