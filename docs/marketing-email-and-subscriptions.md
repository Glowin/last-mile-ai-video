# 每封营销邮件的必需页脚

HTML 与纯文本版本均须包含上面的邮政地址，以及清楚的 `Unsubscribe from all marketing emails` 链接；允许无需登录回复退订。可用基础人工入口：`mailto:support@kakareel.com?subject=Unsubscribe%20from%20all%20KakaReel%20marketing`。不得用不存在的 `/unsubscribe` 路由、模板占位符、登录或付费步骤冒充可用退订。

启用营销发送前先完成：真实退订收信验收、记录被抑制地址、所有批次发送前排除、撤回营销同意不影响账户／交易通知；独立保存可审计同意来源。若接入 ESP，使用其有效的一键退订 URL 与 List-Unsubscribe 能力，并验收重复退订与后续批次抑制。发送脚本、人工群发和第三方代发都适用，不能只改一个模板。

FTC 指引要求有效物理邮政地址、明确退出方式、退出机制至少维持发送后30天，最迟10个工作日兑现退订。当前不发送，所以不能把未建的抑制名单或不存在的发送器标作已验收。[官方依据](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business)。
