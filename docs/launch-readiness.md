# 2026-10-25 实测增量

- Pancake 两项问题已通过客服邮件发出并回读核对，未附密钥或身份资料。指定微信群尚未发送；用户明确要求走原生微信能力，不使用 Computer Use。已验证的单成员群艾特入口与尚未独立验收的无艾特群文本入口不能混为一谈。
- 登录后的 [Seedance 生成页](https://vibetoken.cn/models/bytedance/seedance-2-5/text-to-video) 显示 720p／5 秒报价 ¥6.426，关闭音频后报价不变；页面将其标为估算，按实际输出时长结算，不将其当作已发生费用。
- 经 KakaReel 公开 API 建立独立预览会话后，仅提交一次 Seedance 720p／5 秒、16:9、无音频文生测试。任务返回 `failed`，未获得视频；没有使用购买积分。原请求 ID、请求体及响应保存在库外受限验收目录，不公开账户配置。此项是线上 API 验收，**不是浏览器端完整生成验收**。
- 首次失败已触发本轮费用授权停止条件；未提交 Kling 或图生任务，也没有重试 Seedance。只读查询原 `client_request_id` 返回 404／未找到。当前界面余额未见变化，但尚无该请求的最终扣费记录，故实扣仍待核，不能以失败或查无记录断言零收费。
- 当前实现没有保留本次上游失败的状态码／安全错误分类，无法从已保存的任务状态区分提交被拒与模型运行失败。已核现行 [Seedance API 文档](https://docs.vibetoken.cn/zh/bytedance-seedance-2-5-api/text-to-video)，模型 ID 与 ratio／resolution／duration／generate_audio／output_format 参数形式一致；这不证明具体失败原因。
- 独立隔离测试已完成：成本模块 20 项、worker 崩溃与退款资格 4 项、支付对账 11 项、审核模块 14 项。均使用真实 PostgreSQL 与合成供应商，不构成真实视频或正式支付验收。模块接线、完整回归及部署仍待主会话验收。
