# KakaReel

江昪于 2026-10-20 确认：面向海外视频生成用户，做 All-in-One 视频生成站；接入 VibeToken，覆盖 Seedance、Kling、MiniMax H3。品牌域名选定 `kakareel.com`，Logo 与吉祥物使用鸮鹦鹉。2026-10-20 已在 Cloudflare 完成注册，注册管理页面确认状态为 Active。域名注册成功不代表网站已经部署。

《最后一海里计划》是公开直播系列，目标是展示从创意、开发、上线、首位付费用户到 US$100 收入的过程。KakaReel 是这次系列的产品，代码开源。未宣称已有用户或收入。

## 当前实现

- 英文首页、三个模型落地页、工作台、公开开发介绍、预览条款与隐私说明。
- 文生视频、单张图片生视频；模型对应的时长、比例、分辨率与声音选项。
- 服务器端调用 VibeToken；任务写入 PostgreSQL，查询状态、预览与打开视频保存。
- 同一浏览器的会话历史；签名 HttpOnly cookie、邀请口令、全站每日任务上限。
- 请求 ID 落库后才提交；超时标记状态未知，同一 ID 恢复，避免重复付费生成。
- Docker 单应用容器＋独立 PostgreSQL，目标是既有 Hostinger VPS 上的 Dokploy。

邀请制与每日任务上限是本轮 MVP 的实现选择，用于有限预算的演示。尚不是完整会员系统；清除 cookie／退出会失去当前会话历史入口。支付、套餐、积分、跨设备账号、自动素材保留与删除流程尚未实现。

## 调研如何落地

依据 [竞品报告](research/2026-10-19-ai-video-sites.md)：首屏说明输入和输出、明确进入工作台的按钮、模型落地页承接具体需求、示例提示词降低开始门槛、FAQ 解释价格与使用边界。模型入口保留选择进入工作台；公开页面有独立标题、描述、canonical 与 sitemap；工作台不索引。

首页示例是明确标注的提示词概念插画，不冒充实际视频。还没有真实生成作品和实际用户证言。公开价格须先核对账户计费，再上线支付。

## 上线验收入口

1. 已完成：2026-10-20 注册 `kakareel.com`，Cloudflare 成功页与注册管理页确认 Active。账单及注册人资料保留在 Cloudflare 账户，不写入公开仓库。

3. 江昪完成 VibeToken 账户准备后，配置项目专用密钥，核对真实计费，并授权有限真实生成测试。
4. 逐模型验证文生／图生的真实提交、状态、视频播放与保存；记录实际成本和失败情况。
5. 先邀请一位真实用户完成任务，再围绕反馈推进账号、支付和 US$100 目标。
